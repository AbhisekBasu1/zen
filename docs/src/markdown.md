# Markdown

Markdown is the primary workflow for Zen.

Zen treats Markdown as repository infrastructure, not just formatted prose. A Markdown file may be documentation, but it may also be an instruction file, a plan, a runbook, a review artifact, or durable context for an AI coding agent.

## Editing

The editor supports normal text editing for Markdown files, including multi-cursor editing, selections, undo and redo, and file navigation.

## Preview

Markdown preview renders the current document in a separate pane. This is part of the supported product surface and should remain available in minimal builds.

Use preview when checking headings, lists, links, images, code fences, and document structure.

## Code blocks

Markdown documents often contain code fences. Zen keeps enough language support for common code reading and editing, but it is not trying to be a full language-server-driven IDE.

## Files in repositories

Markdown frequently lives beside source code. Open the whole folder when you need search, Git status, and navigation across related files.
