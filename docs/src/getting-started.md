# Getting started

## Open a project

Open a folder when you want project-wide search, file navigation, Git context, and access to the Markdown files that define the repository's human and agent-facing context.

Open a single file when you only need to read or edit one document.

## Edit Markdown

Markdown files open in the editor like normal text files. Use the editor for writing, navigation, selection, copy and paste, undo and redo, and basic code-style editing operations.

Common repository Markdown includes:

- `README.md`.
- `AGENTS.md`.
- `CLAUDE.md`.
- `.github/copilot-instructions.md`.
- Planning docs.
- Architecture docs.
- Runbooks.
- Changelogs.

## Preview Markdown

Markdown preview is required product functionality. Use the preview command from the command palette or the application menus to open a rendered view beside the editor.

Useful defaults inherited from the editor core may include:

- `cmd-k v` for opening preview to the side.
- `cmd-shift-v` for opening preview.

If a shortcut is unavailable in your build, use the command palette and search for Markdown preview.

## Search

Use file search for the current document and project search for the current folder. Project search is one of Zen's retained core workflows because agent instructions and project plans are often spread across multiple Markdown files.

## Git context

Open a Git repository as a folder to see file changes and repository context. Git and GitHub visualization are retained because Markdown changes can change how humans and agents understand the project.
