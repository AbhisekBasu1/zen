# Branding

The public product name is Zen.

Zen is a calm, repo-native Markdown workspace for humans and AI agents. The name is a deliberate pun on Zed: this fork keeps the editor craft, but strips the broader IDE surface down to a focused repository context workspace.

Zen is independently maintained and is not affiliated with Zed Industries.

## Product position

Use this core line when describing the app:

```text
Zen is a calm, repo-native Markdown workspace for humans and AI agents.
```

Short tagline:

```text
Find your center in the repo's Markdown.
```

Sharper product promise:

```text
Read, edit, preview, search, and review the Markdown that runs your repository.
```

## What Zen is

Zen is for:

- Repository documentation.
- Agent instruction files.
- Planning documents.
- Specs and architecture notes.
- Runbooks and changelogs.
- Markdown review inside Git workflows.
- Lightweight code reading when documents refer to implementation details.

## What Zen is not

Zen is not:

- A full IDE.
- A notes app.
- A hosted knowledge base.
- A built-in AI assistant.
- A collaboration platform.
- A terminal or debugger replacement.

## Visual direction

Zen should feel calm, focused, and repository-native, not mystical or generic wellness software.

Recommended direction:

- Graphite and warm paper base colors.
- Moss, ink, or muted green accent for Git/repository context.
- A simple app icon based on a document pane, centered mark, or quiet `Z` shape.
- Avoid Zed's angular lightning-like identity and upstream color associations.

## Attribution language

Use this language when explaining lineage:

```text
Zen is a fork of Zed, substantially simplified and rebranded as a Markdown-first repository workspace. Zen is independently maintained and is not affiliated with Zed Industries.
```
