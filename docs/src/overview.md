# Overview

Zen is a calm, repo-native Markdown workspace for humans and AI agents.

It helps you read, edit, preview, search, and review the Markdown that runs a repository:

- README files.
- Agent instructions.
- Plans and implementation notes.
- Specs and architecture docs.
- Runbooks and changelogs.
- GitHub issue and pull request templates.

Zen keeps the parts of the Zed editor core that are useful for this workflow:

- A fast editor for Markdown and code files.
- Markdown preview.
- File and project search.
- Project navigation.
- Git and GitHub visualization.

It intentionally removes or de-emphasizes the broader IDE platform surface:

- Built-in AI assistants.
- Multiplayer collaboration.
- Remote development.
- Extensions marketplace.
- Terminal workflows.
- Debugger workflows.
- Accounts, telemetry, and cloud services.

The goal is not to be a smaller Zed distribution. The goal is to make the repository's Markdown layer calm, legible, and easy to maintain.
