# Search

Search is a retained core workflow.

## Current file search

Use current-file search when you need to find text inside the open document.

## Project search

Use project search when a folder is open and you need to find text across Markdown, code, and supporting files.

Project search matters because repository context is distributed. Instructions may live in `AGENTS.md`, tool-specific files, docs folders, GitHub templates, and implementation plans.

Search should remain useful even though broader IDE features have been removed. It is one of the main reasons to keep the editor project model instead of reducing Zen to a single-file viewer.
